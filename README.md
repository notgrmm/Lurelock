# Lurelock
Lurelock is an open-source web extension designed to protect users from phishing attacks. It detects suspicious websites, links, domains, and online content that may steal sensitive information. With transparent, community-driven development, Lurelock aims to provide lightweight, reliable, and privacy-focused protection for safer browsing.
